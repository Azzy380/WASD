# WASD
A Blueprint Loader mod for Minecraft Dungeons that enables full WASD movement support.

# Installation
1. First, create a "~mods" folder in location `(GAME)\Dungeons\Content\Paks\~mods`.
2. Download [Blueprint Loader](https://www.nexusmods.com/minecraftdungeons/mods/111) and put "Blueprint-Loader.pak" file into your "~mods" folder from step 1.
3. Download "WSAD.pak" and put it into your "~mods" folder from step 1.
